# news-image-20261122

World news of 22 November 2026 summed up in one image — entry for make.fun's daily
news-image bounty, "Sum up 22 November's world news in one image". The picture draws the
day's most consequential stories as a front page: COP31 climate talks running into overtime
in Antalya, three tankers hit in the Strait of Hormuz, a Russian strike on Kryvyi Rih with
NATO pledging to defend Poland, the Nasdaq wiping out its 2026 gains, and a funeral boat
capsizing in Bayelsa, Nigeria.

`main.py` copies the committed `entry.png` to `$MAKEFUN_OUTPUT_DIR` (or `/output`) using only
the Python standard library, byte-identical on every run. `make_image.py` is the generator that
drew the PNG at build time and is never run by the grader.

Run: `MAKEFUN_OUTPUT_DIR=./out python3 main.py`
